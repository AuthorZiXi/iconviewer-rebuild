# Attribution & Legal notes

**IconViewer Rebuild** is an independent, from-scratch Win32 program that reproduces the
behaviour of **IconViewer 3.02** by Bot Productions.

## The original

* IconViewer 3.02, Copyright (C) 2008 Bot Productions
* Product page: <https://www.botproductions.com/iconview/iconview.html>
* The original is a Windows Explorer property-page shell extension (freeware).

## What this project is

* An **independent implementation**. All source code here was written for this project.
* **No code, binaries, icons, bitmaps, help files or other assets from the original package
  are redistributed.** The application icon was drawn from scratch (see `tools/icon`),
  the UI was rebuilt from scratch, and the program does not load or link against any
  Bot Productions module.
* Behaviour (which resource types are read, how device images are decoded, the wording of
  short UI labels and the layout of the property page) was studied from the original
  program's **publicly documented behaviour** and from its help file, so that users of
  IconViewer find the same workflow here.
